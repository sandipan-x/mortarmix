# MortarMix

Mortar mix calculator: bags needed from your brick or block count, N/S/M type picker, waste slider, and sand-cement site-mix breakdown.

## Features
- Mortar type picker (N, S, M)
- Waste allowance slider
- Sand and cement breakdown for site mixing
